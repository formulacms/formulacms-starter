# formulacms Community starter

formulacms is a self-hosted, AI-native, multilingual full-stack CMS for Next.js
teams. The admin, Convex backend, typed content model, and public renderer ship
together as one application that a site owner can inspect and evolve.

This repository is a clone-and-own starting point, not a hosted CMS service and
not a headless content API. The shipped site, content types, and Slice Types are
examples; owners are expected to adapt the routes, presentation, content model,
integrations, and supporting code for their project.

it as OSI open source unless the applicable license has converted under those

Use [CONTEXT.md](CONTEXT.md) for the product's content-authoring vocabulary and
[the content-model guide](docs/starter/content-model-authoring.md) for reviewed
extension workflows.
